lists every inventoried first-party file, module summary and public top-level symbol. Its symbols
are navigation aids rather than a stable exported API. The tables below add the context that
AST inspection cannot supply: boundaries, neighboring modules, tests and when to edit a subsystem.
All linked source and tests refer to the documented baseline.

## AI: preparation, extraction, recovery and publication

The [AI architecture](../architecture/ai-analysis-pipeline.md) gives the detailed sequence.
