# docs/development/

`index.md` maps module contracts; `contributing.md` covers safe focused changes and real fixture/test gates; `documentation.md` explains canonical guides, nav/asset allowlist, local preview, publication inspection and docs-group lock updates.

Contribution examples use feature/ branches; bugfix/ and task-appropriate prefixes are allowed, codex/ is prohibited. Public development docs do not require ignored agent files.

All project KNOWLEDGE.md maps are tracked for humans and agents, including maps inside otherwise ignored context folders; documentation.md explains this repository/public-site distinction.
