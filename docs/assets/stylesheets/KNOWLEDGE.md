# docs/assets/stylesheets/

`extra.css` — Original Celadon/celadon and Ink/slate palettes; nine additional palettes
come from the shared registry via overrides/main.html. Shared tokens include native search,
code syntax, tables and keyboard controls. System typography, translucent header, focused navigation/search, pill actions,
real-product landing preview, investigation columns and installation panel. Forms, tables,
code and guides use consistent borders/radii; narrow layouts stack. Feedback responds
immediately; reduced motion/transparency and increased contrast have static/solid variants.
No page entrance or looping animation; no remote font dependency.
