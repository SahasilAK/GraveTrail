# Concepts

Understand what the graph means before using it to assess a change.

- [Projects and workspaces](projects-and-workspaces.md): imported files, retained versions and freshness.
- [Lineage and columns](lineage-and-columns.md): dependencies, references and derivations.
- [Evidence and coverage](evidence-and-coverage.md): original source, inference and unresolved boundaries.
- [Local analysis and optional AI](local-and-ai.md): separate workflows and network disclosure.

in the [UI reference](../USER_GUIDE.md).
