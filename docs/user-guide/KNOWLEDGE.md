# docs/user-guide/

Task-based UI workflows over shared services. Start with static/no-AI analysis; independent AI and focused assistance are explicit separate choices. Imported source never executes.

- `index.md` — workflow hub and links to detailed/canonical references.
- `lineage-builder.md` — Authored schemas versus canvas catalog, placement, joins, shortcuts, trace colors, save/clear, JSON handoff and export scope.
- `sources.md` — ordinary/dbt import, SQL source types, progress, skip reasons and inventory.
- `analysis.md` — static analysis and publication stages, diagnostics, cache and optional AI.
- `explore.md` — exact asset selection, traversal, table expansion, column links and graph controls.
- `evidence.md` — relationship-to-original inspection, hash/version/statement coordinates and evidence limits.
- `columns.md` — default transformation graph, evidence selection, direct references and trace limits.
- `exports.md` — reports, source bundles, interactive HTML, XLSX and SVG/PNG; revision, completeness and source-disclosure choices; authored canvas JSON transfer and schema-only exports.
- `ai-analysis-flow.md` — protocol5 independent extraction, source/context completion, file consolidation, saved operation graph and atomic inferred publication.
- `ai-analysis-controls-and-recovery.md` — model token allocation, optional run ceiling, durable part/request/attempt counters, cancellation/unknown outcomes, resume/replay and lazy retained Inputs/Outputs. Live reasoning display is paused; durable recovery remains.

Screenshots use synthetic fixtures with recipes in development/screenshots.md. The SQL tutorial also explores the larger pub.all_kpis view.
