# Examples

Learn with safe repository fixtures, then apply the same investigation to your code.

- [SQL tutorial](sql.md): inherited seven-layer pipeline and original evidence.
- [SAS tutorial](sas.md): temporary WORK steps and persistent dependencies.
- [dbt tutorial](dbt.md): project import, resources and macro consumers.
- [Interactive lineage](interactive-lineage.md): a downloadable snapshot without installing the app.

Examples demonstrate supported behavior on known inputs, not universal parser/model
accuracy. Read [coverage limits](../concepts/evidence-and-coverage.md).
