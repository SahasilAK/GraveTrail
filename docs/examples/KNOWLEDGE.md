# docs/examples/

Reproducible safe tutorials, separate from real user data and live provider qualification.

- `index.md` — choose SQL, SAS, dbt or interactive-control example.
- `sql.md` — supplied SQL ZIP, pub.all_kpis upstreamdepth30, logical persistent-table/relationship/source expectations and exact original evidence.
- `sas.md` — supplied SAS ZIP, WORK temporary stages, evidence and conservative runtime/macro limits.
- `dbt.md` — synthetic retail source-mode ZIP, fct_orders/resources/macro impact, package/version identities and CLI reproduction; generated artifacts have separate fixtures.
- `interactive-lineage.md` — sandboxed app-generated customer-summary snapshot, four assets/three relationships, controls/source details, safe HTML download and explicit browser-offline verification limits.

Interactive HTML is recreated by scripts/docs/example.py from tracked scenario fixtures; exact reviewed bytes are digest-allowlisted. Real screenshots/recipes live in assets/images and development/screenshots.md. Do not confuse the small scenario with SQL/SAS archive counts or assert released feature availability from a source example.
