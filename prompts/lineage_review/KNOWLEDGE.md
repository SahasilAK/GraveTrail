# prompts/lineage_review/

Version4 optional project reviewer; cannot invent facts or override local validation.

- `system.md` — Exactly one supported/contradicted/insufficient-evidence verdict per
  host-issued candidate, citing exact visible original segments. Partial expression references identify one-input components; host composition owns complete-expression validation.
- `user_template.md` — One JSON context placeholder; bounded compact candidates omit
  repeated evidence. Every eligible candidate receives a bounded batch; larger singletons get actual envelope checks. Completed IDs do not imply approval of unseen candidates.

Protocol v2 review uses exact host candidate IDs and unit references; the host expands complete citations and deterministic validation remains authoritative.
